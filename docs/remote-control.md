# Remote control

Key codes are LG webOS codes; desktop equivalents in brackets are for testing in a browser.

| Key | Browsing | Player (from v0.4.0) |
|---|---|---|
| ▲ ▼ ◀ ▶ (arrows) | Move focus. Rows remember their last card; Up into the nav lands on the active tab. | ▲▼ change channel (banner, switch after a short pause) · ◀ channel list · ▶ audio/subtitles/quality |
| OK (Enter) | Open / play | Show or hide the info overlay |
| Back 461 (Esc, Backspace) | Overlay → page → nav bar → Home → "Exit FBTV?" | Close overlay → return to browsing |
| CH+ / CH− 33/34 (PageUp/PageDown) | Page through long lists (from v0.3.0) | Next / previous channel |
| 0–9 | Jump to channel number (from v0.3.0) | Type a channel number (2-second window) |
| Play 415 · Pause 19 · Stop 413 | — | Pause / resume; back to live edge when the stream can't rewind |
| Red 403 · Green 404 · Yellow 405 · Blue 406 (F1–F4) | Favourite · Filters · Sort · Search | Favourite · Audio track · Subtitles · Last channel |
| Magic Remote pointer | Hover focuses, click activates. Optional: everything works with arrows. | Same |

Holding an arrow repeats at most every 90 ms. While the search field has keyboard focus, typing, Backspace and
Left/Right stay in the field; Up/Down or Back leave it.
