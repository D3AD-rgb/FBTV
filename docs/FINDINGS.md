# Findings and bugs

Numbered log of bugs (`BUG-###`) and findings (`FND-###`: platform facts, data quirks, decisions forced by
evidence). Reference the ID in commit messages and changelog entries, e.g. `fix(nav): keep focus marker (BUG-001)`.

`Found in` / `Fixed in` hold a tag. Write `Unreleased` while work is in progress; `npm run release` replaces it
with the new tag automatically.

| FND-021 | Data | Unreleased | Fixed | Unreleased | Providers name clubs differently ("US Lecce"/"Lecce", "FC Internazionale Milano"/"Inter Milan", "Bayer 04 Leverkusen", "Stade Rennais FC 1901"/"Rennes", "CA Mineiro"/"Atlético Mineiro", sponsor prefixes such as "Çaykur Rizespor", Turkish dotless ı), and openfootball keeps placeholder dates for fixtures without kick-off times, so TheSportsDB events duplicated openfootball fixtures (up to 16 per league in a sample of rounds). | FND-022 | Data | Unreleased | Workaround | Unreleased | Internet Archive "public domain" marks are set by uploaders and are often false: many recent Hindi and Bengali uploads marked public domain are ripped commercial films ("KGF Chapter 2 (2022) Bengali Dubbed 720p", "Haider (2014)", "Tadap (2021) 480p Pre DVDRip"). An item is only offered when its release year is old enough (1977 or earlier for the US-public-domain English sets, 1965 or earlier for Indian films), its title carries no rip or release tags, undated items come from curated collections, and it is not adult content. Everything else is recorded in the inventory with the reason and without a link. |
